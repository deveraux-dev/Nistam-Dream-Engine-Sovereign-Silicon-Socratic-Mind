# Foreword — This Week

Nine documents. One week. Written down so they can be checked.

This is the canon as it stood on 2026-07-08 — the voice, the engine, the river,
the moons. Not a pitch. Not a promise. A record. If a claim in here is further
along than it earned, it is tagged so, or it is a fault.

**How to read the stamps.** Every claim carries a number, zero to four.

- **0 Ghost** — real in intent, no body yet.
- **1 Design** — true because I decided it and built for it.
- **2 Proven** — built and checked once.
- **3 Verified** — a second set of eyes.
- **4 Live** — proven, and in someone's hands.

The one rule: never state a claim above what it earned. A Ghost worn as a Known
is a false stamp — a red tag, not a sin.

The first two chapters condense all of it. The dossier tunes the telling. The
rest is the long version, in full, unedited.

Read it or don't.
