The Human Connection

A 23-Year Refinement. From Physical Brushstrokes to Low-Level Rust.

In construction, painting, and high-frequency property inspection, subjective interpretation of physical appearance is the source of endless administrative friction, litigation, and rework. Contractors, insurers, and property managers end up arguing over raw photographs—turning evidence back into opinion.

Surface Ledger is the culmination of 23 years of built-environment painting and inspecting experience, translated into bare-metal software. By tokenizing the visual appearance space into discrete, repeatable visual standards (VARS) and analyzing them via advanced multimodal AI, I collapse subjectivity into deterministic, non-repudiable state proofs.

Systems Core

Architectural Axioms

Three pillars engineered for absolute determinism, privacy, and zero dynamic overhead on the execution hotpath.

01

Compute at Rest

Cognitive overhead and complex allocations are shifted entirely upstream. The engine does not solve dispute equations dynamically; it merely reads pre-compiled visual and state definitions.

02

Tick-Bounded Expiry

All memory lifetimes are managed strictly by integer clocks, never wall-clock times. Two nodes replaying the same sequence expire identical envelopes at the exact same logical step, guaranteeing zero drift.

03

Zero Data Retention

Once visual states are verified and attested, raw photos and sensitive metadata are immediately wiped via memory zeroization. Only the rolling cryptographic digest lives on.

The Loop

The Multi-Domain Verification Pipeline

How Surface Ledger marries real-world visual standards, multi-modal LLM classification, and systems-level Rust guarantees under a single, unified execution loop:

  • 1 Multimodal Classification: On-site images are matched against the 23-year VARS visual reference dictionary using Gemini's massive, high-context visual parsing.
  • 2 Integer Collapse: Gemini outputs the visual state classification, collapsing complex real-world state into a pure integer coordinate payload.
  • 3 Sealed Envelopes: The state token is locked in a tick-bounded EphemeralEnvelope wrapper, zeroizing raw memory upon resolution or expiry.
  • 4 Balanced-Trit Ledger: Transitions are appended to an append-only EvidenceChain using a rolling SHA-256 hash algorithm.

Clean Craft

The Rust Core: `forge-envelope`

A look inside the bare-metal code designed for zero dynamic heap allocation, complete safety guarantees, and deterministic evidence chain linkage.

src/lib.rs 100% no_std 
// Initialize a new, rolling evidence hash chain
let mut chain = EvidenceChain::new();

// Pack an on-site VARS state token inside a tick-bounded envelope
let env = EphemeralEnvelope::new(b"VARS_HINGE_STATE_B".to_vec(), 0, 60);

// Resolve the envelope before deadline (at Tick 10)
let link = env.resolve(10, &mut chain);

// The resulting link carries the attested state, while the raw bytes are wiped
assert!(matches!(link.record(), Disposition::Attested(_)));
assert!(link.verify());

// Verify that link_b properly follows link_a chronologically
assert!(link_b.follows(&link_a));
