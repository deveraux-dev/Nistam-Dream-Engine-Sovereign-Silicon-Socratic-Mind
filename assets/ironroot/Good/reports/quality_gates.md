# Quality Gates

## Brand gates

```text
[ ] brand_id exists
[ ] carrier exists
[ ] target filter passes
[ ] resistance resolved
[ ] effect depth defined
[ ] decay rule defined
[ ] counterplay available
[ ] visual/audio state readable
```

## Music / rhythm gates

```text
[ ] event has beat/time mapping
[ ] player timing window fair
[ ] minor quantization <= 40ms
[ ] major physics not quantized
[ ] motif is readable after repeated exposure
[ ] rhythm does not hide critical telegraph
```

## Topology gates

```text
[ ] ResonanceTarget registered
[ ] SDF/topology data valid
[ ] material profile validated
[ ] instrument requirement met
[ ] progression gate passed
[ ] navmesh update valid
[ ] fallback state exists
[ ] terrain operation deterministic
```

## Material gates

```text
[ ] material_id authoritative
[ ] color not used as sole material determinant
[ ] facture/normal/depth checked
[ ] density/friction/audio profile assigned
[ ] shader overlay does not rewrite physics
```

## Animation gates

```text
[ ] Laban writes perceived motion only
[ ] joint limits preserved
[ ] anticipation readable
[ ] recovery fair
[ ] hit-stop does not break input feel
```

## Cultural safety gates

```text
[ ] real cultural grammar not used as exposed fantasy flavor without review
[ ] living tradition references abstracted or permissioned
[ ] sacred/restricted objects excluded or reviewed
[ ] faction doctrine avoids shallow ethnic coding
```
