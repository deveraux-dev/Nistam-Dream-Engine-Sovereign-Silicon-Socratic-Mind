# Cultural Safety Report

## Position

Raga, Indigenous relational grammar, Cree-like syllabics, Navajo handling-class logic, sacred objects, and historical ritual systems may inspire structural design, but they must not be treated as free fantasy fuel.

## Safe use

```text
abstract structural logic
fictionalized modes and glyphs
clear provenance notes
consultation for direct cultural material
avoid sacred use without permission
```

## Unsafe use

```text
directly converting devotional material into combat magic
using living cultural grammar as enemy faction flavor
copying sacred symbols into procedural brands
turning real peoples into aesthetic classes
claiming cultural authenticity without research/collaboration
```

## Recommended field

Every culturally inspired rule or asset should include:

```json
{
  "uses_real_cultural_name": false,
  "uses_sacred_material": false,
  "inspiration_level": "structural|aesthetic|direct",
  "review_required": false,
  "notes": ""
}
```
