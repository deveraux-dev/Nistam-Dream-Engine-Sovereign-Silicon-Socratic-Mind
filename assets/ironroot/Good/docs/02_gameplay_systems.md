# Gameplay Systems

## 1. Brands as executable allegiance marks

A brand is not a decal. A brand is a runtime contract applied to an entity, object, material, memory, corpse, population, or zone.

```text
base_entity + brand_overlay = modified behavioral entity
```

Brand categories:

| Type | Target | Changes |
|---|---|---|
| Allegiance brand | creature / NPC | faction loyalty |
| State brand | creature / civilian | temporary behavior |
| Ontological brand | corpse / soul / relic | what the thing is |
| Zone brand | environment | local rules |
| Memory brand | NPC / ghost | identity/history |
| Material brand | metal / bone / stone | physical/magical properties |

## 2. Factions as musical operating systems

| Faction | Musical doctrine | Controls |
|---|---|---|
| Church | choir, chant, bells, liturgy | obedience, purification, mass conversion |
| Undead / Ironroot Dead | detuned metal, drones, feedback | decay, corpse motion, fear, broken memory |
| Folk / Hearthbound | communal songs, work rhythms | healing, shelter, morale, resistance |
| Forge Guild | hammer rhythm, anvil overtones | metal, armor, gates, constructs |
| Mountain / Stone Orders | horns, throat song, sub-bass | cliffs, caverns, fault lines |
| Witch / Root Factions | lullabies, reed tones, knots | animals, sleep, bargains, hidden paths |
| Court / Nobility | formal strings, dances | contracts, duels, hierarchy |

## 3. Bard as mobile compiler

The bard learns and crosses grammars:

```text
church cadence + folk refrain + undead distortion + stone overtone = hybrid world effect
```

Examples:

| Hybrid | Effect |
|---|---|
| Church hymn + folk chorus | liberate zealots instead of controlling them |
| Undead distortion + stone tone | collapse a crypt from within |
| Folk work-song + forge rhythm | rebuild a bridge rapidly |
| Bell tone + mountain chord | crack a cathedral foundation |
| Bone pipe + lullaby | restore memory to undead |
| Choir harmony + counter-note | invert mass conversion ritual |

## 4. Topology as resonance target

Terrain has a resonant profile. The player does not blast terrain; the player diagnoses and completes a lawful fracture.

Steps:

1. Listen.
2. Reveal fault geometry.
3. Find the fault chord.
4. Match or invert the resonance.
5. Trigger topology mutation if validators pass.

Possible operations:

```text
split_cliff
open_pass
collapse_cave
reroute_water
shear_fortress_wall
raise_buried_ruin
break_shrine_anchor
vent_crypt_curse
```
