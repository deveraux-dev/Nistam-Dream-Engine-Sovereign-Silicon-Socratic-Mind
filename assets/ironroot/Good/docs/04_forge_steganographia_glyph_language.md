# Forge Steganographia Glyph Language

## Core principle

A Forge glyph should be readable at four depths:

1. Aesthetic - it looks and feels right.
2. Phonetic - it can be spoken or sung.
3. Mnemonic - it helps a human remember a process.
4. Executable - it compiles into material, shape, shader, sound, behavior, or state.

## Channel model

| Channel | Meaning |
|---|---|
| Shape | entity type / class / domain |
| Orientation | mode / tense / polarity / direction |
| Color | emotional tone / faction alignment / material state |
| Size | magnitude / priority / scale |
| Position | relationship / hierarchy / dependency |
| Stroke pattern | action type / timing / loop / persistence |
| Sound or chant value | activation / resonance / synchronization |
| Grouping | clauses / subroutines / composite behavior |

## Grammar layers

1. Ontology: self, ally, enemy, leader, territory, resource, shrine, tool, threat, signal.
2. Verbs: move, guard, gather, invoke, build, merge, split, hide, attack, heal, obey, transform.
3. Modifiers: slow, urgent, covert, joyful, sacrificial, synchronized, recursive, defensive, territorial.
4. Logic: if near, if heard, if wounded, if outnumbered, if night, if shrine active.
5. Composition: sequence, branch, loop, priority, inheritance, override, fallback.

## Compiler target

A faction page is not only lore. It is a spell sheet, design sheet, behavior sheet, and compilation target.
