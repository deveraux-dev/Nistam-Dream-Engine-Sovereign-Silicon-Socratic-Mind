# Public-Domain Asset Pipeline

## Stance

A clean source solves permission risk. Human authorship solves ownership strength. Registry validation protects runtime correctness.

## Accepted sources

```text
CC0
Public Domain Mark
explicit open access with commercial reuse
public-domain photos with clear platform terms
government/public-domain sources
```

## Pipeline

```text
public-domain source
-> source/license verification
-> optional photometric / voxel / morphometric reconstruction
-> human slicing into semantic parts
-> optional local Flux variation
-> human touchup / repaint / cleanup
-> atlas assembly
-> socket metadata
-> material/audio/stat metadata
-> procedural recombination rules
-> runtime approval
```

## Five gates

1. Source rights
2. Flux/model/LoRA license
3. Human authorship
4. Similarity/derivation
5. Provenance ledger

## Default classification

```text
Public-domain-reference-derived procedural asset with human-authored slicing, atlas assembly, and AI-assisted variation.
```
