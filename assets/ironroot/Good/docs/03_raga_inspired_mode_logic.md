# Raga-Inspired Mode Logic

## Design stance

Use raga as structural inspiration, not as lootable cultural content.

Preferred framing:

```text
raga-inspired fictional resonance grammar
```

Avoid:

```text
direct extraction of Indian sacred/classical forms into combat spells
```

## Mapping

| Raga concept | Compiler equivalent |
|---|---|
| Aroha | allowed rising phrase |
| Avaroha | allowed falling phrase |
| Vadi | primary resonance tone |
| Samvadi | secondary resonance tone |
| Pakad | recognizable signature phrase |
| Rasa | emotional/psychological effect |
| Time of day | activation window |
| Season | environmental affinity |
| Gamaka | expressive bend/slide rule |
| Drone/tanpura | world anchor / tonal field |
| Tala | rhythm cycle / encounter timing |
| Improvisation | player variation inside rules |

## Design sentence

Raga-like modes define what the world can feel. Tala-like cycles define when the world can change. Brands define who owns the change. Topology defines where the change becomes physical.

## Cultural guardrail

```text
Real raga tradition is reference and structure, not lootable content.
Dirge modes should be fictionalized, credited as inspired by modal/rasa/time-cycle logic, and reviewed before direct naming or sacred use.
```
