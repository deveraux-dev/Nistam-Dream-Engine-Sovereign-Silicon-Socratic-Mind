# Dirge of Ironroot Resonance Compiler v0.1

This bundle combines the Theory-to-Engine Prior Compiler with Dirge of Ironroot's brand, faction music, topology resonance, rhythm-combat, raga-inspired mode logic, and Forge steganographic glyph scripting.

Core doctrine:

> Theory proposes. Registry decides. Validators gate. Music carries. Brand rewrites. Topology remembers. Player performs.

## Folder map

- `docs/` - human-readable compiler doctrine and design notes.
- `rules/` - machine-usable KG_RULE entries in JSONL and Markdown.
- `schemas/` - JSON schemas for events, brands, modes, resonance targets, and provenance.
- `examples/` - example entities, songs, brands, topology events, and faction scripts.
- `tables/` - compiler lookup tables and authority maps.
- `reports/` - friction, gap, quality, and cultural-safety reports.
- `sources/` - source ledger and provenance notes.
- `manifests/` - package manifest and intended usage.

## Production stance

This is not a final runtime implementation. It is a compiler-ready doctrine bundle for designing deterministic procedural systems. Theories and cultural systems are treated as priors, not truths. No single symbolic, musical, visual, or movement cue may directly own runtime truth without registry and validator approval.
