# Generic Transfer

Use the same procedure outside Ironroot by replacing project-specific axes.

## Generic compiler shape

intent -> actor -> pressure -> communication goal -> motion phrase -> timing contract -> state effect -> friction checks -> validation gates

## Replace Ironroot nouns

- Bardic action -> player communication mode
- Vowless/refusal -> non-compliance/restraint/silence/withholding action
- Shadow habit -> adaptive antagonist/player-mirror model
- faction pressure -> institutional/social/system pressure
- event ledger -> save-state/event-state/story-state log
- Name-Shear -> signature world-state warning signal

## Non-negotiable transferable gates

- Motion must not lie about gameplay timing.
- Scripted scenes must write or preserve state truth.
- Gesture must not reveal impossible speaker knowledge.
- Stillness must be framed if it is meaningful.
- Sound may support motion but cannot replace critical visual/state evidence.
- Style polish must not erase readability.
