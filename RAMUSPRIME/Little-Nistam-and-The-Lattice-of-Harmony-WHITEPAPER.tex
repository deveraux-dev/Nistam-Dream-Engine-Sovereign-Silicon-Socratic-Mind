\section{CHAPTER I: THE PROBLEM --- BYTE PAIR ENCODING'S POLYSYNTHETIC FAILURE}

\subsection{Standard BPE: Statistically Blind, Linguistically Ignorant}

Byte Pair Encoding works by iteratively merging the most \emph{frequent} adjacent byte pairs. The algorithm is completely unaware of linguistic structure:

\begin{lstlisting}
Input:  "nicî-wâpamêw" (Cree: "he looks at me")
BPE vocab: English-trained, 50K tokens
Tokenization process:
  1. Split to bytes: n, î, c, î, -, w, â, p, a, m, ê, w
  2. Scan for frequent pairs (English statistics)
  3. Merge high-frequency pairs: "in", "an", "wa"
  4. Result: [n_token, î_token, c_unusual, ...]
  5. UCAS characters (î, ê, â) → fragment into 2–3 byte tokens
Output tokens: ~18 tokens (vs. optimal: ~4-5 morphemes)
\end{lstlisting}

\textbf{The failure modes}:

\begin{enumerate}
  \item \textbf{Out-of-Vocabulary Fragmentation}:
  \begin{itemize}
    \item UCAS (Unified Canadian Aboriginal Syllabics): U+1400--U+167F, U+18B0--U+18FF
    \item Trained on English corpus: 0 occurrences of UCAS in training data
    \item BPE fallback: byte-level decomposition of UTF-8
    \item Result: One UCAS glyph $\to$ 1--3 tokens (confirmed via agent research)
  \end{itemize}

  \item \textbf{Morpheme Destruction}:
  \begin{itemize}
    \item Cree morphemes carry meaning (\emph{wâp} = see, \emph{am} = him, \emph{êw} = 3rd person)
    \item BPE merges based on byte frequency, not morphemic boundary
    \item Result: Token sequence loses linguistic coherence
  \end{itemize}

  \item \textbf{Entropy Explosion}:
  \begin{itemize}
    \item 50K vocabulary: high entropy (many possible next tokens at each step)
    \item No grammar to constrain: every token is independently probable
    \item Result: Shannon entropy $\sim$11--12 bits/token (low information density)
  \end{itemize}
\end{enumerate}

\section{CHAPTER III: THE MEASUREMENT REVOLUTION --- ANTI-SHANNON PURITY}

\subsection{Shannon Entropy: Measuring Disorder}

Classical information theory defines entropy as:

\[H_1(P) = -\sum_{i=1}^{N} p_i \ln(p_i)\]

\begin{itemize}
  \item Measures \textbf{disorder} (peaks on uniform random, zero on pure state)
  \item Intuitive: ``How uncertain is the next token?''
  \item \textbf{Hardware cost}: $\ln(x)$ requires transcendental ALU (multi-cycle stall)
  \item For token sequences: high entropy = ``tokens scattered across vocab'' (BPE)
\end{itemize}

\subsection{Rényi Entropy (Order 2) \& the Logarithm Tax}

Collision Entropy is:

\[H_2(P) = -\ln\left(\sum_{i=1}^{N} p_i^2\right)\]

Still requires transcendental outer shell. But something interesting happens if we \textbf{strip the logarithm}:

\[N \times \text{IPR} = N \sum_{i=1}^{N} p_i^2\]

\subsection{Anti-Shannon: Normalized Inverse Participation Ratio}

\textbf{Definition}:

\[\text{IPR}_{\text{norm}} = N \times \sum_{i=1}^{N} p_i^2\]

\textbf{Properties}:

\begin{center}
\begin{tabular}{lll}
\toprule
Property & Value & Meaning \\
\midrule
\textbf{Range} & $[1, N]$ & 1 = chaos, N = pure state \\
\textbf{Arithmetic} & Pure polynomial FMA & No transcendentals, $O(N)$ ops \\
\textbf{Direction} & $\uparrow$ = order & Inverted vs. Shannon \\
\textbf{Hardware} & Dot-product $p \cdot p$ & Runs at full clock, no stalls \\
\textbf{Cache fit} & L1 shared memory & GPU workgroups, no frame drops \\
\bottomrule
\end{tabular}
\end{center}

\textbf{Example}:

\begin{lstlisting}
Uniform distribution (chaos):
  p = [1/N, 1/N, …, 1/N]
  Σ p_i² = N × (1/N)² = 1/N
  N × IPR = 1  ← Minimum purity

Pure single-frequency (order):
  p = [1, 0, 0, …, 0]
  Σ p_i² = 1
  N × IPR = N  ← Maximum purity
\end{lstlisting}

\textbf{In linguistic terms}:

\section{CHAPTER V: CREE SOVEREIGNTY AND LINGUISTIC REALITY}

\subsection{Why Grammar Constraints Are Not Optional}

Standard machine learning treats language as \textbf{pattern completion}: given N tokens, predict the (N+1)th by maximizing probability under a learned distribution.

This works for English-like languages where word order and morphology are relatively loose. But Cree doesn't work that way:

\textbf{Animate vs. Inanimate Agreement} (mandatory):
\begin{lstlisting}
Animate subject:  "kî-wâpamêw"    (he saw [animate object])
Inanimate object: "kî-wâpamâtêw"  (he saw [inanimate object])

Morpheme difference: -êw vs. -âtêw
This is NOT optional. Violating agreement = ungrammatical.
\end{lstlisting}

\textbf{Obviative Tracking} (mandatory):
\begin{lstlisting}
Proximate (main): ni-wâpamâw     (I see him [proximate])
Obviative (other): ni-wâpamâhkêw (I see him [obviative])

Morpheme change signals a shift in narrative focus.
Violating obviative marking = confusing the listener.
\end{lstlisting}

\textbf{Direction Hierarchy} (mandatory):
\begin{lstlisting}
2 > 1 > 3 > 3' (second person > first > third animate > third inanimate)

"You see me"   = complex morpheme set (2 > 1)
"I see you"    = different morpheme set (1 > 2)
"He sees him"  = inverse marking required (3 > 3')

Word order doesn't encode this; morphology does.
\end{lstlisting}

\textbf{The point}: Cree grammar is \textbf{not a probability distribution}. It's a set of \textbf{rules that must be satisfied}. A BPE tokenizer treats it as ``likely next tokens,'' missing the \textbf{mandatory constraints}.

The ZPSR enforces these constraints at the token boundary, ensuring:
\begin{enumerate}
  \item Only grammatically valid tokens can be selected
  \item No grammatical violations can emerge (even with N heads of attention)
  \item The language remains intelligible to native speakers
\end{enumerate}

\subsection{B.1 Formal Derivation of N×IPR}

Starting from Rényi Entropy of order $q=2$:

\[H_2(P) = -\frac{1}{q-1} \ln \left( \sum_{i=1}^{N} p_i^q \right) = -\ln \left( \sum_{i=1}^{N} p_i^2 \right)\]

Taking the inverse (anti-entropy):

\[-H_2(P) = \ln \left( \sum_{i=1}^{N} p_i^2 \right)\]

Exponentiating both sides:

\[e^{-H_2(P)} = \sum_{i=1}^{N} p_i^2\]

Scaling by $N$:

\[N \times e^{-H_2(P)} = N \sum_{i=1}^{N} p_i^2 = \text{N×IPR}\]
