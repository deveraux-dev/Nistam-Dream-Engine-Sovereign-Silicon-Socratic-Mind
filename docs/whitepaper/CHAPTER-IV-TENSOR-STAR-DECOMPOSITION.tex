\section{The Discrete S13 Core Specification}

The central core tensor $\call{G}$ captures cross-modal correlations. In the S13 engine, this continuous core is mapped onto a discrete balanced-ternary lattice:

\begin{definition}[S13 Core Packing]
Let $\call{G} \in \{-1, 0, *Ñ}~{R_1 \times \dots \times R_N}$ be partitioned into blocks of length $G = 128$ or $256$, each associated with a continuous group scale $Lalpha_g = \max_{k \in G} |\call{G}_{\text{cont}, k}|$. Within each group, individual trits $t_k \in \{-1, 0, *Ñ}$ are packed in chunks of 5 into canonical MSB-first Base-243 bytes:
\[
  \text{byte} = \sum_{j=0}^4 (t_j + 1) \csdot 3^{4-j} \quad \in [0, 242]
\]
Byte values in $[243, 255]$ trigger \texttt{S13Error::SentinelDetected}.
\end{definition}

This yields \textbf{95% memory compression} on the core relative to FP32, transforming dense floating-point multiplication into single-cycle SIMD table lookups and integer adds.

\subsection{Closed-Form Leaf Update via Contracted Complements}

When the core $\call{G}$ is quantized to balanced ternary, the initial factor matrices $U^{(n)}$ experience a \emph{quantization shock}. To eliminate this residual error without altering the discrete core, we solve:

\[
  \min_{U^{(n)}} \left\\| \call{X}_{(n)} - U^{;(n)} \call{Y}_{(n)} \right\\}_F^2 + \lambda \\|U^z(1)]\\}_F^2
\]
where $\call{Y} = \call{G}_{\text{S13}} \times_{m \neq n} U^{(m)}$ is the complement tensor contracted across all modes except $n$, and $\call{Y}_{()}$ is its mode-$n$ matrix unfolding.

The closed-form analytic solution is:
\[
  U^{(n)} = \call{X}_{(n)} \call{Y}_{(n)}^T \left( \call{Y}_{(n)} \call{Y}_{(n)}^T + \lambda I \right)^{-1}
\]

\section{SO(5) Geodesic Astrolabe Commutativity}

\begin{theorem}[SO(5) Leaf Commutativity]
Let $\call{R} \in SO(5)$ be a double-plane rotation matrix parameterized by Givens angles ($theta_{zw}, \phi_{wv}$) acting on mode $n$ of a 5D star catalog tensor $\call{X}$. Then rotation of the full continuous tensor is algebraically isomorphic to rotating the peripheral leaf matrix $U^{(n)}$:
\[
  \call{R} \cdot_{n} \call{X} = \call{G}_{\text{S13}} \times_1 U^z(1)} \dots \times_n (\call{R} U^z(1)}) \dots \times_5 U^z(5)}
\]
\end{theorem}

\begin{proof}
By multilinear associativity of tensor mode multiplication, rotation commutes directly with the leaf operator while leaving the S13 balanced-ternary core $\call{G}$ resident in LI cache.
\end{proof}
